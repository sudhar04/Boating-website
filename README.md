# 🚤 Boating Website

A modern and responsive boating website built with **React.js** and **Vite**. The application provides an elegant user experience for exploring boating services, premium packages, booking rides, and contacting the service provider.

---

## 🌐 Live Demo

> https://boating-website.vercel.app/

---


## ✨ Features

- 🏝️ Modern and responsive landing page
- 🚤 Premium boating packages
- 📅 Online booking flow
- 📍 Location information
- 🖼️ Interactive gallery
- ⭐ Customer testimonials
- 📞 Contact section
- 📱 Mobile-friendly design
- ⚡ Fast loading with Vite
- 🎨 Smooth animations using Framer Motion

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/sudhar04/Boating-website.git
```

Navigate into the project

```bash
cd Boating-website/boating-app
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
